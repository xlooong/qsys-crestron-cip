# System

> 来源: https://help.qsys.com/q-sys_10.4/#Control_Scripting/Using_Lua_in_Q-Sys/System.htm

Use the System functions to return Q-SYS environment information.

## Methods

| Method | Description |
|--------|-------------|
| System.BuildVersion | Returns the build version number of Q-SYS environment. |
| System.LockingId | Returns the Q-SYS Core's Locking ID, which is used for Q-SYS feature license activation. |
| System.IsEmulating | Returns a Boolean indicating whether the design is emulating or running on a Core. |
| System.MajorVersion | Returns the major version number of Q-SYS environment. |
| System.MinorVersion | Returns the minor version number of Q-SYS environment. |
| System.Version | Returns the complete version number of Q-SYS environment. |
