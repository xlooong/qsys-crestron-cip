# LPeg

> 来源: https://help.qsys.com/q-sys_10.4/#Control_Scripting/Using_Lua_in_Q-Sys/LPeg.htm

LPeg is a pattern-matching library for Lua, based on Parsing Expression Grammars (PEGs). LPeg defines patterns as first-class objects; patterns are regular Lua values (represented by userdata).
