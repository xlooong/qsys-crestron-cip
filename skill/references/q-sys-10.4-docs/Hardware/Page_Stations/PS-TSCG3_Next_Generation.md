# PS-TSCG3 Next Generation Page Station
> 来源: https://help.qsys.com/Content/Hardware/Page_Stations/PS-TSCG3_Next_Generation.htm

The Q-SYS PS-TSCG3 Touchscreen Paging Station pairs with the TSC-70-G3 touchscreen and Q-SYS control engine to enable paging applications across transportation, education, hospitality, entertainment and beyond. By leveraging Q-SYS Control capabilities, the Q-SYS PS-TSCG3 paging peripheral provides live paging and pre-recorded message playback, alongside traditional functions such as BGM management and device control in a modernized way.

## Features

- PS-TSCG3-G
- PS-TSCG3-H
- TSC-70-G3
- Supports standard paging elements and non-paging control elements

|  |  |
|---|---|
| PS-TSCG3-G | PS-TSCG3-H |

## Design Components

- Status/Control (Touch Screen)
- Lightbar (TSC-G3, PS-TSCG3 Series)
- Sensors
- Mic/Control (Page Station)
